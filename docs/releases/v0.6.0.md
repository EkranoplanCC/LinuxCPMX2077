## What's new in v0.6.0

### New look
- The whole app has a new Cyberpunk-style theme: dark maroon and charcoal panels, teal angled frames and yellow highlights. It is drawn with styles only; no game artwork or logos are included.
- Wording across the app now states what was checked and against which source, instead of vague phrases.

### Get Mods
- Download straight from a mod's card with the ⬇ button, with a choice of file when a mod has several.
- Download progress shows right in the Get Mods tab.
- Files you already downloaded are not downloaded again.
- Author names open a list of that author's mods.

### Installed mods
- **Mod page** button opens the mod's page.
- Each mod's Nexus requirements show a **You have** column, and a **Get missing (N)** button fetches the ones you don't have.
- The version column is now called **Mod version**.
- When Ultra+ (the path tracing mod) is installed, an **Ultra+ recommendations** card lists the mods the Ultra+ team recommends next, and which of them you already have.
- Custom categories are now tags.

### Graph
- **Group by** groups the graph and flowchart by mod type or by tag.

### Netrunner (formerly Diagnostics)
- The Diagnostics tab is renamed **Netrunner**.
- New **File map**: a folder tree of every installed mod file, plus a by-mod view, showing which files are in use, overridden by another mod, missing, or belong to a mod that is turned off.
- Crashes & logs now shows the last session's errors first, a startup timeline of what loaded, and warnings for 12 known problem mods.

### Debug terminal
- A new debug terminal window shows Nexus API requests and file operations live, styled like an in-game terminal.

### Windows (early preview)
- First release with a Windows installer (`CPMX2077_0.6.0_x64-setup.exe`). It finds Steam, GOG and Epic installs on Windows.
- It has only been built and checked in CI and has **not been run on a real Windows PC yet**. Expect rough edges.
- The installer is not code-signed, so Windows SmartScreen asks once (More info, then Run anyway).

### Docs
- New getting-started tutorial and user guide in the `docs/` folder, linked from the README. The README has new screenshots.
