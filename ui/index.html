            Get mods

            Downloads you start on nexusmods.com in your normal browser don't reach CPMX2077 yet. Downloads from CPMX2077's own Nexus window work either way.

            Sign in on nexusmods.com in your browser and approve this app. Your password never passes through the manager.

            Or use an API key

            Paste your personal API key from nexusmods.com → Site preferences → API Keys. It's checked with Nexus and stored in your system keyring, never in a plain file.

            API requests
            Every request to Nexus, newest first. Bars show how long each took. Your API key is never shown.
